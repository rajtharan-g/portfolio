# Rajtharan Gopal — Portfolio

A static, responsive portfolio site prepared for GitHub Pages. No build step or dependencies are required.

## Preview

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a **public** GitHub repository named `portfolio` and push this folder to its `main` branch.
2. In the repository, open **Settings → Pages** and set **Source** to **GitHub Actions**.
3. The workflow in `.github/workflows/deploy.yml` will publish the site. The project site URL will be `https://YOUR-USERNAME.github.io/portfolio/`.

After setup, each push to `main` automatically updates the live site.

## Before publishing

- Review the project descriptions and metrics for accuracy and confirm they are okay to share publicly.
- The ALLEN, Noon Academy, and Square Off sections use current images from their public App Store listings. They illustrate the current apps and may not show the screens you worked on.
- Replace any company or product links that are no longer appropriate.
- Add project screenshots only if you have the right to share them and they contain no confidential information.
- Consider using a custom domain if you own one.
